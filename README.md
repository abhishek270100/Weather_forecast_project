# Weather Forecast Project
A real-time weather application that fetches data using a weather API.

## Features
* Real-time temperature display
* Location-based search
* Date and time integration
* Weather condition descriptions (e.g., Light rain, Mist)

## Tech Stack
* HTML5
* CSS3 
* JavaScript
